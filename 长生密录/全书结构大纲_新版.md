# 《大唐炼药师的民国诡局》（暂定名）/《长生密录》 全书结构大纲

## 一、 作品核心商业定位与写作基调

*   **题材分类**：民国悬疑 / 都市修仙 / 错位时空 / 寻宝解密
*   **字数预估**：约100万字（约500章）
*   **写作防毒（Anti-AI）底线**：
    *   **禁忌词汇**：绝对禁用“宛如、倒吸一口凉气、宿命般、眼底闪过一丝”等俗套形容词。
    *   **动作替代情绪**：不写“他很愤怒”，写“他指尖的茶杯无声粉碎”。
    *   **拒绝话剧腔**：对话必须短促、符合角色利益，不讲废话。
    *   **结尾悬念**：每一章结尾、每卷结尾绝不写哲理总结，必须留“钩子”（如新危机爆发、意外发现）。
*   **核心爽点（金手指）**：【大唐玄天阁炼气术与古医术/相术】。降维打击民国武术与早期火器。
*   **核心代价**：强行越阶使用残缺术法（不老方等长生器物），会剥离情感记忆，变得极度理智与冷酷。这种代价转化为与女配/女主之间的极致拉扯。

## 二、 核心人物与前世今生羁绊

### 1. 【大唐原点：玄天阁同门恩怨】
*   **孟三迁（主角）**：大唐最高修仙宗门【玄天阁】的绝顶天才、国师、师兄。狂放不羁，为躲避炼制毒丹的死局，引发阵法爆炸逃亡至1930年上海。
*   **明月 / 书生（反派一）**：玄天阁内门弟子，孟三迁的师弟。一生刻苦却永远被天才师兄的光芒掩盖，内心充满自卑与隐秘的野心。爆炸中被卷入，早降临50年（1880年）。他在民国创立/加入【破军社】，誓要炼出师兄没炼成的长生药，证明自己超越了师兄。
*   **青鸾 / 夜莺（女配，白月光）**：玄天阁专属丹房的洒扫侍女。地位卑微，得孟三迁随手传授一招“弹射铜钱”防身。爆炸时唯一冲向火海救人者。早降临40年（1890年）。化身杀手“夜莺”，只为借情报网寻找师兄。

### 2. 【民国原点：新的羁绊】
*   **苏曼音（女主）**：1930年上海滩女学生。为了寻找失踪的哥哥，救下孟三迁并互相利用。她没有武力，但手腕极其高明，后期成长为掌控多方势力的“民国情报女王”。她是孟三迁在情感逐渐丧失时的唯一锚点。
*   **霍千秋（终极BOSS）**：长生会话事人，隐藏极深的幕后黑手。将长生与科技结合的疯子，也是破军社背后的真正金主。

## 三、 百万字全书卷纲（连载节奏布局）

### 第一卷：十里洋场，大唐狂客（第1-80章 / 约16万字）
*   **本卷核心目标**：绝境反杀，立住主角“降维打击”的逼格；赚取原始资本（搞钱搞玉石）；引出阵营悬念。
*   **剧情主轴**：
    *   **【黄金开局】**：1930年大雨，孟三迁在黄浦江边/刑讯室濒死醒来。原身因撞破走私被灭口。孟三迁利用极致微操（水汽毒阵），反杀黑帮。
    *   **【错位与结盟】**：带伤逃亡时闹出错位认知笑话。被苏曼音救下。苏曼音看中其潜力，隐瞒其存活消息，结成寻人/寻宝同盟。
    *   **【搞钱与原始积累】**：用大唐古医术治好巡捕房探长威尔逊，获得特权。大闹地下古董黑市与赌石大会，靠千年底蕴捡漏极品玉石，恢复部分炼气修为。
    *   **【结仇破军社】**：夜莺初次试探（认出唐朝暗器手法但未相认）。孟三迁卷入连环血案，用炼丹手段破局，正式对上【破军社】。为了拿到去北平的通行证和殷墟情报，离开上海。

### 第二卷：津门迷局，鬼市点灯（第81-150章 / 约14万字）
*   **本卷核心目标**：过渡地图，拉伸民国纵深；夺取开启殷墟的钥匙（引路罗盘）；苏曼音初露峥嵘。
*   **剧情主轴**：
    *   **【军阀截胡】**：火车途经天津被地方军阀强行扣留。孟三迁发现军阀头目手里有一件唐朝法器（罗盘）。
    *   **【鬼市黑吃黑】**：天津地下鬼市副本。与倒卖国宝的外国探险队、天津地头蛇斗智斗勇。孟三迁点天灯设局，连环黑吃黑夺得罗盘。
    *   **【女主成长】**：苏曼音在天津利用交际场和心机，初步建立自己的情报网。夜莺暗中护航，两人留下玄天阁细节的伏笔。

### 第三卷：北平殷墟，甲骨天书（第151-240章 / 约18万字）
*   **本卷核心目标**：夺取第一件器物（甲骨秘匣）；清算原身因果；第一层代价爆发。
*   **剧情主轴**：
    *   **【学术降维】**：潜入北平辅仁大学。针对民国专家束手无策的甲骨文，孟三迁用“认字”的方式碾压学术界。顺手帮原身报仇，斩断肉身旧因果。
    *   **【三十六层地宫】**：安阳殷墟深潜探险。遭遇破军社精锐、地下机关兽与毒物。大唐阵法全开，极致碾压。
    *   **【师弟现身】**：书生明月出场。“师兄，时代变了！”——第一次同门斗法。
    *   **【代价爆发】**：开启第一残卷“不老方”。孟三迁强行越阶，被剥离情感记忆，变得极度冷酷。苏曼音的笔记本成为他唯一的记忆锚点。

### 第四卷：金陵风雷，六朝幻梦（第241-350章 / 约22万字）
*   **本卷核心目标**：夺取青铜镜；多方势力角逐；【全书最高潮：夜莺身份大揭晓】。
*   **剧情主轴**：
    *   **【权贵交锋】**：苏曼音查明哥哥死于长生会献祭，潜入金陵权贵圈复仇。孟三迁作为隐秘保镖，一明一暗端掉破军社据点。
    *   **【紫金山大混战】**：日本间谍、破军社、长生会三方混战。孟三迁引动紫金山龙脉，施展道家借法镇压全场。
    *   **【六朝幻境】**：双人入局。直面大唐当年炸炉原罪。
    *   **【玄天阁重聚】**：获取青铜镜。**夜莺摘下面纱，单膝跪地：“玄天阁奉剑侍女青鸾，见过孟师兄。”**此时孟三迁因代价失去共鸣能力，形成极致的情感错位拉扯。
    *   卷末：霍千秋现身秒杀明月，撕破伪装，终极阴谋浮出水面。

### 第五卷：魔都暗城，玉匣镇魂（第351-440章 / 约18万字）
*   **本卷核心目标**：获取汉代玉匣；夜莺献祭与挽救真灵（毒点转化）；绝地反弹前的低谷。
*   **剧情主轴**：
    *   **【城市游击】**：重返上海，发现租界已被霍千秋掌控。化整为零展开猎杀。
    *   **【法租界地下城】**：大逃杀模式开启。孟三迁、苏曼音、夜莺三人小队绝境探秘。
    *   **【真灵剥离（催泪高潮）】**：霍千秋发动“时间锁”。夜莺为救孟三迁挡枪，身体逆生长即将消散。孟三迁剧痛中凭借极致意志冲破封锁，吐血施展唐朝招魂禁术，将青鸾“一缕本命真灵”强行封入玉匣残片（温养胸前，留下复活希望）。
    *   孟三迁重伤被擒入水牢。苏曼音逃脱，开始谋划惊天营救。

### 第六卷：吴淞海战，天命长生（第441-500章 / 约12万字）
*   **本卷核心目标**：终极决战；民国科技与大唐道法的巅峰碰撞；粉碎祭祀。
*   **剧情主轴**：
    *   **【集结残兵】**：苏曼音动用前百万字积累的人脉（天津军阀、北平校尉、上海青帮），上演宏大群像营救。
    *   **【大唐护国杀阵】**：吴淞口炮台决战。孟三迁以风水杀阵引动黄浦江潮水，配合烈性军火，将破军社精锐摧枯拉朽般全歼。
    *   **【最终抉择】**：放弃使用“不老方”维持冷血战力，选择燃烧自身命格，手刃霍千秋，将其推入时空乱流。长生祭祀破灭。

## 四、 尾声：时间的答案
*   三个月后，苏曼音将三器碎片与封存着夜莺真灵的古钱融合，亲手打磨出一枚玉璧。
*   1937年，南京风雪夜。成为战地护士的苏曼音在难民潮中看到孟三迁。他胸口佩戴着温养夜莺真灵的玉璧。两人隔着人海，行大唐拱手礼与民国鞠躬礼，相视一笑，各自汇入时代洪流。
*   **终章留白**：现代博物馆中，碳14鉴定玉璧上留下了唐朝、清末和1932年三个不同时代的指纹印记。（全书完）
